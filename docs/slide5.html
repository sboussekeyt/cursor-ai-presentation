MCP & Écosystème de Contexte : Tout Connecter

🔌 MCP (Model Context Protocol)

  • Standard ouvert pour connecter LLMs à sources externes
  • Créé par Anthropic (créateurs de Claude)
  • Architecture client-serveur extensible
  • Permet d'enrichir le contexte avec données en temps réel
  • Compatible avec Cursor, Claude Code et autres outils
